# AI味翻车案例库 / AI-Flavored Writing Failures

收集"翻车"的、具有明显 AI 味的不好文字，作为写作质量的反面教材。
A collection of "failed" texts with an obvious AI flavor, used as negative examples of writing quality.

与 `humanizer`、`qu-ai-wei`（去AI味）等技能互补：那些技能负责"改"，本库负责"记错在哪"。
Complements skills like `humanizer` and `qu-ai-wei` (de-AI-flavoring): those handle "fixing", this repo handles "recording where it went wrong".

## 收录规则 / Collection Rules

- 每当用户说出一个不好的 AI 味文字例子，就收录进本文件夹，**按天归档：一天一个文件，同一天的多个例子都追加进同一个 `YYYY-MM-DD.md`**。
- Whenever the user gives a bad AI-flavored example, archive it here, **filed by day: one file per day; multiple examples from the same day are appended to the same `YYYY-MM-DD.md`**.
- 文件名格式：`YYYY-MM-DD.md`（如 `2026-09-14.md`），不按例子单独建文件，省空间。
- File name format: `YYYY-MM-DD.md` (e.g. `2026-09-14.md`); not one file per example, to save space.
- 单条示例尽量短（一段或几句话即可），重点是"错得典型"。
- Each example should be short (one paragraph or a few sentences); the point is "typically wrong".

## 每条例子格式（写在当日文件内）/ Example Format (inside the daily file)

```markdown
# 简短标签（如：模板连接词堆砌 / 空泛评价 / 无主语AI腔）

## 原文字
> 粘贴翻车的原文

## 问题标签
- 套话/模板连接词（首先其次最后、值得注意的是、总的来说）
- 空泛评价（非常、极其、深刻揭示了、具有重要意义）
- 无主语AI腔（令人惊叹的是、无独有偶）
- 逻辑断裂 / 与前文割裂
- 堆砌术语不解释
- 其他：_____

## 为什么翻车
一两句说清它哪里读着别扭、假、或劝退。

## 改写对照（可选）
> 改后的版本
```

# Short label (e.g.: template connectors piled up / vague praise / subject-less AI tone)

## Original text
> paste the failed original

## Problem tags
- Clichés / template connectors (first, second, lastly; it is worth noting; in summary)
- Vague praise (very, extremely, profoundly reveals, of great significance)
- Subject-less AI tone (it is amazing that, similarly)
- Broken logic / disconnected from context
- Jargon piled up without explanation
- Other: _____

## Why it failed
One or two sentences on what reads awkward, fake, or off-putting.

## Rewrite (optional)
> the revised version
```

## 用途 / Use Cases

- 给写作/改稿时做"负面清单"核对。
- A "negative list" to check against when writing / revising.
- 训练"去AI味"判断力的素材库。
- A material library for training "de-AI-flavoring" judgment.
- 复盘自己稿件时，对照本库自查。
- Self-review your own drafts against this library.
